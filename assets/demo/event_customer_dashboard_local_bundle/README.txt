LOCAL EVENT CUSTOMER DASHBOARD

This bundle is standalone and local. It does not connect to GitHub.

1. Extract this ZIP to a folder on your computer.
2. Open a terminal in the extracted folder (the folder containing this HTML file).
3. Run: python3 -m http.server 8000 --bind 127.0.0.1
4. Open: http://127.0.0.1:8000/cyberpunk_customer_dossier_event_customer_flow_local_csv.html

Keep the Result/ and prototypes/ folders beside the HTML file. They contain the event-specific CSVs used by the dashboard. Do not open the HTML as file://; the browser must load it over the local HTTP server.
